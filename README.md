# 🛍️ FlowShop

Uma loja online desenvolvida em HTML, CSS e JavaScript.

## ✨ Funcionalidades

- 🛒 Catálogo de produtos
- 🛍️ Carrinho de compras
- ❤️ Favoritos
- 📦 Pedidos
- 🔎 Pesquisa de produtos
- 📱 Interface responsiva

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

## 📚 Sobre o projeto

O FlowShop é um projeto de aprendizado desenvolvido para praticar
desenvolvimento web e criação de lojas virtuais.
